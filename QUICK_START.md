# Pressure Room quick start

1. Start the app and sign in with your email magic link. Cloud stories are persisted in Supabase across devices.
2. Create a story and record its premise and central dramatic question.
3. Add an episode, create scenes, and write screenplay text in **Write**.
4. Inspect the character's Want, Moral Boundary, Pressure, Choice and consequence in **Structure**.
5. Test the story with **Diagnose** (Story MRI and Suspense Engine).
6. Use **Room → Export & backup** to download a portable `.pressureroom` copy. You can also export PDF, Markdown or Fountain text.

The optional browser-local mode is separate: it saves only on that device and is not the same as an authenticated Supabase cloud workspace.
